# دليل حل مشاكل النشر - E-Commerce Website

## المشاكل الشائعة وحلولها

### 1. خطأ صفحة المنتجات (Error on Products Page)

#### السبب:
- عدم وجود منتجات في قاعدة البيانات
- مشاكل في الاتصال بقاعدة البيانات
- صور مفقودة للمنتجات

#### الحلول:

##### أ. إضافة متغير البيئة:
```bash
ASPNETCORE_ENVIRONMENT=Development
```

##### ب. تشغيل البيانات التجريبية:
```sql
-- في SQL Server Management Studio أو أداة قاعدة البيانات
-- شغل ملف SampleData.sql المرفق
```

##### ج. إضافة الصور الافتراضية:
- ضع الصور في مجلد `wwwroot/images/products/`
- الصورة الافتراضية: `phone1.jpg`

### 2. إعداد قاعدة البيانات

#### للاستضافة الجديدة:
```sql
-- إنشاء قاعدة البيانات
CREATE DATABASE ECommerceDB;

-- تشغيل البيانات التجريبية من ملف SampleData.sql
```

### 3. إعداد Redis Cache

#### في لوحة الاستضافة:
- تأكد من أن خدمة Redis تعمل
- عنوان الخادم: `mariem-ayman.runasp.net`
- اسم المثيل: `ECom:`

### 4. إعداد البريد الإلكتروني

#### في لوحة الاستضافة:
- استخدم إعدادات Gmail SMTP
- فعل "Less secure app access" في حساب Gmail
- أو استخدم App Password للحسابات الحديثة

## خطوات النشر:

### 1. قبل النشر:
- تأكد من وجود جميع الملفات المطلوبة
- اختبر الموقع محلياً
- احفظ نسخة احتياطية من قاعدة البيانات

### 2. أثناء النشر:
- ارفع ملفات المشروع
- شغل البيانات التجريبية إذا لزم الأمر
- اختبر جميع الصفحات

### 3. بعد النشر:
- اختبر صفحة المنتجات
- اختبر إضافة المنتجات للسلة
- اختبر نظام تسجيل الدخول

## استكشاف الأخطاء:

### إذا ظهر خطأ عام:
1. أضف متغير البيئة `ASPNETCORE_ENVIRONMENT=Development`
2. أعد تحميل الصفحة لرؤية تفاصيل الخطأ
3. ابحث عن الخطأ في السجلات

### إذا كانت الصور لا تظهر:
1. تأكد من وجود مجلد `wwwroot/images/products/`
2. أضف صورة `phone1.jpg` كصورة افتراضية
3. تحقق من أن MediaController يعمل بشكل صحيح

### إذا كانت قاعدة البيانات لا تعمل:
1. تحقق من صحة connection string
2. تأكد من وجود جداول البيانات
3. شغل البيانات التجريبية من SampleData.sql

## الملفات المطلوبة:
- `wwwroot/images/products/phone1.jpg` (صورة افتراضية)
- `SampleData.sql` (بيانات تجريبية)
- `appsettings.Production.json` (إعدادات الإنتاج)

## الدعم:
إذا واجهت مشاكل، تأكد من:
1. وجود جميع الملفات المطلوبة
2. صحة متغيرات البيئة
3. وجود بيانات في قاعدة البيانات
4. عمل خدمة Redis
